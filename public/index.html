Connect your GitHub account

Paste a personal access token. It is stored encrypted in an httpOnly cookie on this server and is never sent to the browser again.

Which token do I need?
  • Fine-grained token (recommended): Repository access = the repos you want, permissions Contents: read & write, Pull requests: read & write, Metadata: read-only.
  • Classic token: scope repo (and workflow if you edit GitHub Actions files).
  • Create one at github.com → Settings → Developer settings → Personal access tokens.

Paste your file block

One fenced code block per file. The path lives in the info string of the fence:

```python path=src/mathx/ops.py action=upsert
def add(a, b):
    return a + b
```
  • path= (required; aliases file=, src=, title=, or just the bare path as the first word).
  • action= (optional): upsert (default), create, update, append, prepend, delete.
  • exec or mode=755 (optional) to make a new file executable.
  • The language is taken from the fence, otherwise guessed from the file extension (cosmetic only).
  • Optional front matter at the very top: repo:, branch:, pr_title:, pr_body:, commit_message:, draft:.
